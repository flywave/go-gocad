# go-gocad

Go library for reading and writing GOCAD (Geological Object Computer Aided Design) files.

## Supported formats

- TriSurf (.ts) — triangulated surfaces with properties
- PLine (.pl) — polylines

## Features

- Parse GOCAD TriSurf 1.0 and PLine 1.0
- Extract vertex, triangle, color, and property data
- Export to OBJ format
- Write GOCAD TS format
